# Solum brand assets

Every file here is generated by [`build.py`](build.py). The geometry lives in one
function, so no variant can drift from another. If a mark needs changing, change it
there and re-run:

```bash
cd brand && python3 build.py
```

Do not hand-edit the SVGs.

---

## The mark

A cadastral plot boundary with a chamfered corner, three survey crosshairs on the
square corners, and a filled control point on the chamfer.

It is drawn from the same vocabulary the product uses: the boundary is a plot, the
crosshairs are survey ticks, the filled dot is the corner the setback is measured
from. It is not an abstract shape that happens to sit next to the name. Someone who
works with plot sheets should recognise what it is without being told.

Coordinates sit on a 40x40 grid with the artwork inset from 5 to 35, which leaves
built-in clear space on all four sides. The boundary carries the accent colour, the
survey marks carry ink. That split matters: it keeps the orange as one deliberate
element rather than flooding the whole mark.

## Files

| File | Use |
| --- | --- |
| `solum-mark.svg` | Primary. Orange boundary, ink marks. Light backgrounds. |
| `solum-mark-black.svg` | One colour ink. Print, fax quality, anywhere the accent will not reproduce. |
| `solum-mark-white.svg` | One colour white. Dark backgrounds, photography. |
| `solum-mark-mono.svg` | Uses `currentColor`. Inline in HTML where it should inherit the surrounding text colour. |
| `solum-logo-horizontal.svg` | Mark plus wordmark, 176x48. The default lockup. |
| `solum-logo-horizontal-white.svg` | Same lockup for dark backgrounds. Boundary stays orange, wordmark and marks go white. |
| `solum-logo-stacked.svg` | Mark above wordmark, 116x84. Square-ish spaces, app icons, social avatars. |
| `favicon.svg` | Tighter crop (`viewBox="3 3 34 34"`) with heavier strokes so it survives 16px. |
| `favicon-inline.html` | The favicon as a `data:` URI in a ready-to-paste `<link rel="icon">`. |

The favicon is a separate drawing on purpose. The full mark at 16px turns the
crosshairs into grey mush, so that variant trades the built-in clear space for
stroke weight.

`solum.html` and `site/index.html` both ship as single self-contained documents, so
they carry the icon inline rather than fetching a file. Their `<head>` holds the tag
from `favicon-inline.html`. If the mark changes, re-run `build.py` and replace the
`<link rel="icon">` line in both files.

## Colour

| Token | Hex | Where |
| --- | --- | --- |
| Accent | `#FF6B19` | Plot boundary |
| Ink | `#1A0E08` | Survey marks, control point, wordmark |
| Paper | `#FAF6F0` | Background the primary mark is drawn against |

These are the app's `--accent-500`, `--ink` and `--paper`. The brand and the product
share one palette; there is no separate marketing colour scheme.

On backgrounds other than paper or white, use the white or ink variant rather than
the primary. The accent orange on a mid-tone background loses its contrast and stops
reading as a highlight.

## Clear space and minimum size

**Clear space:** one quarter of the mark height on every side. At 40px that is 10px.
The mark's own 5-unit inset covers part of this, so in practice keep 5px of true
margin at 40px and scale from there. Nothing else sits inside that band, including
rules, image edges and other logos.

**Minimum sizes:**

- Mark, digital: 20px
- Mark, print: 8mm
- Horizontal lockup, digital: 120px wide
- Horizontal lockup, print: 32mm wide
- Below 20px, use `favicon.svg` instead

Below the lockup minimums the wordmark's letterspacing collapses and the mark's
chamfer disappears. Use the mark on its own instead of shrinking the lockup.

## Wordmark

The lockups set SOLUM in **Urbanist 800** with `-0.01em` letterspacing, as live text.

Live text keeps the files small and lets the SVGs inherit the site's already-loaded
webfont, which is right for the web. It is wrong for anything leaving our control.
A recipient without Urbanist installed falls back to Inter, then Helvetica, and the
lockup silently becomes a different logo.

**Before any print or third-party handoff, outline the text.** With the font file
present:

```bash
inkscape solum-logo-horizontal.svg --export-text-to-path \
  --export-plain-svg -o solum-logo-horizontal-outlined.svg
```

Outlined copies are not committed here because they cannot be regenerated by
`build.py` without the licensed font. Generate them per handoff and keep the live
text version as the source.

## Don'ts

- Do not recolour the boundary. Orange or white or ink, nothing else.
- Do not fill the boundary. The plot is empty because the plot is undeveloped.
- Do not remove the survey marks to "simplify" it. They are the reason the mark is
  a survey drawing rather than a generic pentagon.
- Do not add a shadow, glow, gradient, or outer container. The mark is line art.
- Do not rotate, skew, or stretch. Scale uniformly.
- Do not rebuild the lockup by placing the mark next to typed text. Spacing in the
  lockups is set in `build.py` and is not eyeballed.
- Do not place the primary mark on a mid-tone or busy background. Switch variants.
